# ApexPlanet Task 3 – Deep-Dive Analysis & Interactive Dashboarding

## Project Overview

This project explores sales performance and customer segmentation using a cleaned sales dataset. It combines KPI development, deep-dive analysis, and interactive dashboarding in Microsoft Power BI.

## Tools

* Microsoft Power BI
* DAX
* Microsoft Excel / CSV
* SQL Server

## Core KPIs

* Total Sales
* Transaction Records
* Total Units Sold
* Average Sales per Transaction Record
* Average Selling Price

## Analysis Areas

* Monthly sales trends
* Product revenue analysis
* Category performance
* Customer age-group segmentation

## Deliverables

* Power BI report (`.pbix`)
* Deep-dive analysis report (`.pdf`)
* Dashboard screenshot
